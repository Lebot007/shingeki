# 進撃 · Portfólio Shingeki — Lebot

Portfólio pessoal de **Lebot** (developer & creator) com temática inspirada em *Shingeki no Kyojin* (Attack on Titan). Um único arquivo HTML — sem build, sem framework, sem dependência de runtime.

**🔗 Site no ar:** <https://lebot007.github.io/site-shingeki-portfolio/>

## O que tem dentro

- **Gate de entrada** com kanji 進撃 e botão de entrada
- **Hero** com brasas em canvas, tilt 3D e parallax
- **Quem sou** — bio + alter ego (Eren Yeager)
- **Arsenal** — habilidades em 6 dossiês de equipamento de manobra
- **Expedições** — projetos (portfólio Tokyo Ghoul, este site, streams, Spotify)
- **Sinais de fumaça** — redes sociais: [Instagram](https://www.instagram.com/https.jvalves/), [Twitch](https://www.twitch.tv/Lebotz_gg), [TikTok](https://www.tiktok.com/@lebot_gg), [Spotify](https://open.spotify.com/user/o2fbtdnh53z6t6ca4v6wez8rz) e Discord (`Lebot.gg`, com botão de copiar)
- Acessibilidade: navegação por teclado, skip link, `prefers-reduced-motion`, contraste WCAG

## Stack

HTML5 + CSS3 + JavaScript vanilla em um `index.html`. Fontes via Google Fonts. Nada mais.

## Rodar localmente

```bash
git clone https://github.com/Lebot007/site-shingeki-portfolio.git
cd site-shingeki-portfolio
# abra o index.html no navegador — ou:
python -m http.server 8000
```
